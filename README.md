# To-Do List App 📋

A simple command-line task manager built with Python.

## 📋 Description

This is a terminal-based To-Do List application that allows users to manage their daily tasks. It was built as part of a university course assignment focused on Git and GitHub for software project management.

## 🛠️ Technologies Used

- Python 3

## 📁 Project Structure

```
todo-app/
│
├── todo.py       # Main application file
└── README.md     # Project documentation
```

## 🚀 How to Run


```bash
python todo.py
```

## ✨ Features

- ➕ Add new tasks
- 📋 View all tasks with status
- ✅ Mark tasks as done
- 🗑️ Delete tasks
- 🔄 Simple menu-driven interface
